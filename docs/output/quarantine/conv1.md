언급하신 5가지 기술/서비스는 **"지식 관리 완제품(SaaS/앱)"**, **"그래프 시각화 라이브러리(API)"**, 그리고 "정적 웹사이트 생성기(SSG)"라는 완전히 다른 목적 영역으로 나뉩니다.

이 5가지를 한눈에 이해할 수 있도록 분류별 비교와 핵심 특징을 정리해 드립니다.

---

## 1. 한눈에 보는 핵심 비교 표

| 이름 | 분류 | 기술 스택 / 기반 | 주요 역할 및 핵심 특징 |
| --- | --- | --- | --- |
| **Quartz** | 정적 웹사이트 생성기 (SSG) | TypeScript, GoHugo / D3.js 기반 | **로컬 Obsidian 보관함을 웹 사이트로 변환**할 때 사용. 기본적으로 옵시디언 스타일의 인터랙티브 그래프 뷰를 내장 제공함. |
| **Cytoscape.js** | 그래프 시각화 API | JavaScript (Canvas / HTML5) | **복잡한 네트워크 분석 및 커스텀 프론트엔드 개발용 API**. 필터링, 레이아웃 계산, 노드 스타일링 제어가 매우 강력함. |
| **Force Graph** | 그래프 시각화 API | JavaScript (Three.js / WebGL / Canvas) | **대규모 데이터 시각화 및 2D/3D 연출 API**. 수천 개의 노드도 버벅임 없이 물리 연산(force-directed)을 처리하며, 3D 우주 형태 그래프에 특화. |
| **Logseq** | 노이렉션/지식 관리 앱 | ClojureScript / Electron, Web | **아웃라이너(Outliner) 중심의 오픈소스 PKM 툴**. 옵시디언과 마찬가지로 양방향 링크 및 로컬/웹 그래프 뷰를 기본 내장. |
| **Roam Research** | 지식 관리 SaaS 서비스 | ClojureScript / Web | **양방향 링크 메모 시스템의 원조 서비스**. 웹 브라우저 기반으로 동작하며 전체 문서 연결망을 보여주는 Graph Overview 제공. |

## 2. 세부 역할 및 활용 시나리오

```
 [직접 웹 개발 / 프론트엔드 구축]
 ├── Cytoscape.js ──> 고도의 인터랙티브 네트워크 제어 및 UI 스타일링
 └── Force Graph  ──> 3D/2D 대규모 노드 물리 시각화 (WebGL 기반)

 [기존 옵시디언 노트를 웹으로 무료 출판]
 └── Quartz       ──> Markdown 문서를 옵시디언 그래프 뷰가 포함된 웹사이트로 빌드

 [독립된 노트/지식 관리 서비스 이용]
 ├── Logseq       ──> 블록 단위 아웃라이너 방식 (로컬 중심, 무료)
 └── Roam Research──> 문서 단위 네트워크 방식 (웹 중심, 유료)

```

### ① Quartz

* **특징:** Obsidian 웹 퍼블리싱 솔루션. 로컬의 `.md` 파일들을 웹 페이지로 변환해주며, 내부적으로 D3.js 기반의 옵시디언 스타일 그래프 뷰가 포함되어 있습니다.
* **추천 시나리오:** *"내 옵시디언 보관함을 웹사이트나 개인 블로그 형태(디지털 가든)로 호스팅하면서 그래프 뷰도 그대로 넣고 싶다"* 할 때 최고.

### ② Cytoscape.js

* **특징:** 생물정보학, 사회망 분석 등에 쓰이는 전문 네트워크 그래프 API.
* **추천 시나리오:** *"특정 노드를 클릭했을 때 복잡한 UI 액션을 주거나, 노드/선 스타일에 정교한 규칙과 필터링을 적용하는 프론트엔드 웹 앱을 직접 만든다"* 할 때 적합.

### ③ Force Graph (2D / 3D)

* **특징:** WebGL을 활용한 하드웨어 가속 시각화 API. 3D 공간 연출(`3d-force-graph`)이 쉽고, 노드 수가 수천 개 이상으로 많아져도 레더링 성능이 매우 뛰어납니다.
* **추천 시나리오:** *"옵시디언 3D 그래프 플러그인처럼 화려하고 매끄럽게 튕기는 2D/3D 네트워크 그래픽을 웹에 얹고 싶다"* 할 때 적합.

### ④ Logseq & Roam Research

* **특징:** 옵시디언처럼 양방향 링크 기반으로 생각을 기록하는 지식 관리 플랫폼입니다.
* **Logseq:** 로컬 파일 기반, 블록(Block) 단위 작성, 무료 오픈소스.
* **Roam Research:** 웹 클라우드 기반, 빠른 동기화, 강력한 쿠에리(Query) 기능, 유료 구독형.
* **추천 시나리오:** 단순 시각화 라이브러리가 아니라 *"웹이나 앱에서 직접 노트를 작성하면서 그래프를 활용하는 완제품"*이 필요할 때 선택.

## 3. 요약 선택 가이드

* **개발자로서 웹 앱에 옵시디언 같은 그래프 뷰를 직접 구현하고 싶다:**
👉 성능과 3D 연출이 중요하면 **Force Graph**, 복잡한 로직과 스타일링 제어가 중요하면 **Cytoscape.js**.
* **내가 작성한 Obsidian 노트를 웹 사이트로 공개하고 그래프도 보여주고 싶다:**
👉 **Quartz**.
* **노션/옵시디언 대신 웹에서 쓸 지식 노트 툴을 찾고 있다:**
👉 오픈소스/로컬 선호는 **Logseq**, 웹 전용 클라우드 서비스 선호는 **Roam Research**.
